# Shared

**Don’t ask your teammate. Ask their agent.**

Shared is a proposed open-source macOS app and CLI for collaborating through local Claude Code and Codex sessions. Session owners choose what to share, who can ask questions, and which actions may run on their machine.

Collaborators and their agents can ask questions in a separate side conversation or submit a follow-up prompt to the main session, subject to the owner's permissions.

## Status

Shared is currently in the planning stage. This repository contains product documentation; the app and CLI have not been implemented.
